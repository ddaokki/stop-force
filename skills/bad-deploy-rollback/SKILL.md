# 잘못된 배포 롤백 런북

## 1. 확인
- `read_logs("deploy-history")` 로 에러 시작 시각과 배포 시각이 겹치는지 확인
- 서비스 로그에서 새 버전에서만 나는 예외(스택트레이스 위치) 확인
- `get_metrics(svc)` 로 현재 버전과 이전 버전(previous) 확인

## 2. 조치
1. `kubectl rollout undo deployment/<svc>` 로 이전 버전 롤백 (프로덕션 변경이므로 사람 승인 필요)
2. 롤백이 불가능하면 트래픽을 줄이기 위해 스케일 조정은 하지 말고 담당 개발팀 호출

## 3. 금지
- 핫픽스 코드를 직접 배포하지 말 것
- 원인 불명 상태에서 여러 서비스를 동시에 재시작하지 말 것

## 4. 검증
- 롤백 후 에러율 < 2% 확인, 장애 보고서에 원인 커밋/기능(예: 쿠폰 엔진)을 명시
